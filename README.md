# Healthy — личный health tracker

Первый MVP на реальной WHOOP-выгрузке.

## Источник
В `data.json` импортированы:
- physiological_cycles.csv
- sleeps.csv
- workouts.csv
- только 4 категории WHOOP Journal: migraine, anxiety, alcohol, caffeine

Важно: исторический WHOOP Journal содержит только факт yes/no для этих вопросов. Количество бокалов, кофе после обеда, интенсивность тревоги/мигрени и лекарства из этих CSV достоверно восстановить нельзя — эти поля вводятся вручную в новом журнале.

## Экраны
- Сегодня
- Журнал
- Аналитика
- История

## Запуск
Открыть `index.html` через локальный статический сервер или GitHub Pages.
